🎵 OTW Radio Embed Widget

Drop-in widget for third-party websites

Widget Features

🎛️ Live Player

Compact audio player with volume control and now-playing info

📅 Expandable Schedule

Users can expand to see the next 4 programming blocks

🔗 Header Navigation

Direct links to OTW Radio home and schedule pages

📱 Responsive

Auto-adjusts height when expanded/collapsed. Works on all devices

Embed Code

Copy and paste this code into your website where you want the radio player to appear:

<!-- OTW Radio Widget --> <div id="otw-radio-widget"> <iframe id="otw-radio-iframe" src="https://onestowatch.live/embed/widget" style="width: 100%; height: 180px; border: none; border-radius: 8px;" allow="autoplay" title="OTW Radio Player" ></iframe> </div> <script> // Auto-resize iframe based on content window.addEventListener('message', function(e) { if (e.data.type === 'resize') { const iframe = document.getElementById('otw-radio-iframe'); if (iframe) { iframe.style.height = e.data.height + 'px'; } } }); </script>
📌 Note: The iframe starts at 180px height (compact mode). When users expand the schedule, it automatically grows to ~500px. The JavaScript listens for resize messages from the widget to adjust the height smoothly.

Customization Options

Fixed Width Container

Wrap the widget in a fixed-width container:

<div style="max-width: 400px; margin: 0 auto;"> <!-- OTW Radio Widget code here --> </div>

Sidebar Integration

Perfect for website sidebars. The widget stays compact by default and expands on demand.

Row Integration

Use in a multi-column layout (like the demo page). Set a max-width on the parent container.
